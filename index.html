About Calculo

Calculo is a collection of interactive calculus simulations. It is a work in progress, and probably always will be; new topics get added as time allows. The goal is simple — to let you see the ideas of calculus move, instead of only reading them.

About the Author

Calculo was built by Knovay, a small independent project making interactive tools for learning math and science. (Ricky — swap this paragraph for your own note: who you are, why you built it, and an email or link for feedback. That personal line is what makes a site like this feel real.)

How it was made

Every simulation is built by hand as a single web page with plain JavaScript and the canvas element — no plugins, no sign-up, and it runs on anything with a browser. Assembled with the help of AI, and checked by a human.

Permissions

Please feel free to use anything here for non-profit educational purposes — project it in class, link it in your notes, or embed a single simulation with the built-in embed link.
